# 通用错误分类

只在 Agent 完成图片盲转写后使用本分类。分类用于检索和统计，不用于自动改写原文。

| 类别 | 通用特征 | 典型检查 |
|---|---|---|
| `latin-digit-confusion` | 拉丁字母与数字外形接近 | 检查数字字段中的 `Q/O/I/l` 等字符 |
| `glyph-confusion` | 形近汉字、相同偏旁或部件替换 | 对比字的偏旁、主体部件和笔画差异 |
| `semantic-character-substitution` | 字形可读但放入短语后语义明显异常 | 保留原字，再与 Excel 和上下文核对 |
| `missing-character` | 图片比基准少一个或多个字符 | 逐字符对齐并记录删除位置 |
| `extra-character` | 图片比基准多一个或多个字符 | 检查重复字、残留字和错误后缀 |
| `duplicate-content` | 段落、句子或标签重复出现 | 为每次出现建立独立实例 |
| `term-inconsistency` | 同一术语在图片不同位置写法不一致 | 建立重复词实例表，禁止标题覆盖正文 |
| `number-unit-conflict` | 数字、日期、温度或单位前后矛盾 | 图内实例与 Excel 分别对比 |
| `punctuation-format` | 标点、全半角、连接符、空格或换行不一致 | 使用严格视图报告差异 |
| `grammar-structure` | 字符可读但存在搭配、成分或语序问题 | 只提出建议，不修改原文栏 |
| `reference-mismatch` | 图片与 Excel 基准存在字符差异 | 记录工作表、单元格和差异操作 |
| `mapping-ambiguity` | 图片区域无法唯一对应 Excel 单元格 | 保留全部候选，交人工映射 |
| `low-confidence-glyph` | 像素模糊、遮挡、压缩或贴边 | 列出所有候选，不作多数裁决 |

## 特征抽取规则

1. 把业务句子缩减为最小字符对或结构模式。
2. 优先记录“为什么容易错”和“怎样检查”，而不是产品、品牌或公司上下文。
3. 同时积累人工确认错误和人工确认可接受写法。
4. 旧案例只用于提高召回或减少重复误报，不能替代当前图片像素和 Excel 单元格。
5. Excel 未被用户指定为权威来源时，分类为双向 `reference-mismatch`，不要生成确定修正方向。
6. 用户在对话中给出的明确纠正、误报或漏报反馈视为人工确认；只保留最小特征，来源使用 `human-copy`，不得保存整段对话。
7. 与图片文字无关的业务规则反馈不进入本问题集，应路由到对应业务 Skill。
