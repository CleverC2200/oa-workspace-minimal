# 停止与失败规则

## 停止整个批次

- 默认 profile 不存在、应用身份不匹配、bot 未 ready 或验证失败；
- 认证、权限、API 路径或公共请求体契约错误；
- owned CLI 无法运行，或写后检查响应缺少 `diff_instances`；
- 回执结构与结果契约不一致。

停止后将尚未处理的 requestId 报告为“未执行”，不切换身份、不绕过检查、不手工拼 token。

## 仅当前实例失败

- requestId 为空、不是数字字符串或不能唯一表示 OA requestId；
- 飞书返回只与当前实例有关的错误；
- 写后检查在 `diff_instances` 中返回当前实例。

记录当前实例“同步未闭环”后，可以继续其他相互独立且已经通过 dry-run 的实例。

## 禁止误报成功

- dry-run 不是真实同步；
- 写入接口返回成功但未执行写后检查，不是闭环成功；
- 检查返回差异、结构不完整或命令非零退出，不是闭环成功；
- 不无条件重试，不用并发或替代接口掩盖失败。
