# TPM 小额市场费规则包

适用于 `workflow_key=tpm_small_marketing_fee`，当前版本 `tpm_small_marketing_fee:4`。复用[共享结果接口](../result-contract.md)和公共取数、证据准备、结果校验及意见输出；差异仅在本流程的科目、附件要求和以下四项规则。不得套用普通小额市场费的 SAP 客户编码或费用承担主体要求。

AI 只形成预审意见，不批准、不退回。判断来自当前流程可回查的字段、关联发票和附件内容。附件缺失属于业务问题；自动读取失败时只说明对应项目未完成核对并请财务查看原单，不得声称申请人未填写字段、未上传附件或单据没有发票。问题结论应指出具体材料、金额或关系，不要求固定句式。

## 固定四项审核

1. 附件完整性：读取各明细预算科目，仅按该科目匹配下表，不按标题或报销事项追加其他科目的要求。同科目的共用制作清单和照片可在整单范围核对，不要求每行重复上传；字段未解析时，仍需检查当前单据已取得的附件内容，不直接判缺。科目可读但不在表中时，按支付截图和发票检查，不因表外科目单独提示异常。科目本身读不清时说明无法确定适用要求。本单仅有一个收款人时，直接比较表单收款人员名称（或收款人名称）与本单关联发票销售方，一致即按对公支付免支付截图；多个收款人时再核对对应关系。无需另取实际付款凭据来证明截图豁免，不能只凭选择了企业支付接口认定豁免。其他必需附件仍需核对。清单盖章、现场定位及照片要求都在本项核对。材料里存在可查看的原图时，本项的 `evidence_refs` 必须引用 `material:prepared.images.<资源id>` 中的具体图片作为内容证据；不得用附件名称、文件大小或上传存在性代替内容核对，也不得据此判通过。未引用任何图片内容证据时本项不得判通过，须写明未完成照片与清单内容核对并交财务核对原单。宿主会在完成审核时复核该要求：材料存在原图而本项判通过且无图片引用时，本项自动降级为需人工判断。
2. 发票关联与金额：核对当前单据 OA“关联发票”及发票金额，同一发票去重计入。单据内已关联发票不要求逐行重复挂票，也不额外要求提供发票金额逐行分摊表；发票挂在某一明细行上不等于金额只属于该行，不能直接把整张发票总额与第一行金额不同判为冲突。存在多支付对象、跨单据或重复票据等明确问题时，再按实际对应关系核对，不凭金额相同推断其他单据或附件的归属。仅纸质发票或收据才核对快递单号、是否已传递或邮寄；收据另核对购买方、事项、金额、收款人姓名、身份证号和手机号。没有纸质发票或收据时，不提示该项附加要求，不另设签字栏目。电子发票本身不是问题。
3. 金额孰低核销：列出可信支付金额、发票金额及适用的盖章制作清单金额，按孰低原则形成核销意见。仅预算科目为 `终端建设费-终端形象制作费` 时，须核对并说明盖章制作清单总额；`推广费用-物料费` 不追加清单盖章要求。已确认对公且免支付截图时，使用申请支付金额与当前单据已关联发票金额核对，申请金额不能写成已实际支付，也不因支付状态为空而另报缺少实际支付金额。多张凭证合计须有可信对应关系并排除重复截图；金额比较不设置容差；金额无法确认或存在明确归属冲突时，说明待核实事实，不因缺少逐行分摊信息单独提示异常。已提供材料中的支付失败、重复和金额冲突仍需报告。
4. 支付公司一致：本流程比较公司名称时，仅统一中英文括号并去掉首尾空白，这些排版差异不构成主体差异；仍保留原值，不改字、展开简称或做模糊匹配。核对报销公司、支付公司、发票购买方是否一致，并说明应选择的实际公司全称支付。无法确认时列出缺失字段或冲突原值，不猜测公司对应关系。收款人与销售方关系属于第一项的支付截图豁免条件，不独立增加审核项。

## 10 类费用科目与附件要求

| 费用科目 | 必需附件 | 专项核对 |
| --- | --- | --- |
| `终端建设费-终端形象制作费` | 发票、广告公司盖章版制作清单、执行后现场定位照片 1 张 | 制作清单内容结合已提供的参考报价单和照片核对数量、样式；参考报价单不是必传附件；清单印章与发票销售方一致；无支付截图时核对收款人姓名与发票销售方一致 |
| `推广费用-物料费` | 发票、制作清单或购买明细、支付截图、制作完成定位照片 | 清单或明细与定位照片一致 |
| `终端建设费-其他` | 发票、支付截图 | 按通用发票和支付对应关系核对 |
| `通路促销-订货会会务费` | 关联申请签报、发票、费用清单、签到表、支付凭据；每个申请不少于 4 张订货会现场多角度全局定位照片 | 逐个申请核对照片数量、全局视角和定位信息，缺少会议材料时明确列出 |
| `推广费用-产品赠品费` | 发票、支付截图 | 按通用发票和支付对应关系核对 |
| `推广费用-试吃品费` | 发票、支付截图、执行试吃定位照片 | 说明照片缺失或定位无法确认的具体情况 |
| `促销员费用-管理费` | 发票、支付截图 | 按通用发票和支付对应关系核对 |
| `促销员费用-激励费` | POS 复核数据表、激励政策（申请签报或签报截图） | POS 表只检查是否上传，不识别表内内容 |
| `促销员费用-统筹福利` | 关联申请签报、发票、支付截图 | 核对签报与当前明细的归属关系 |
| `促销员费用-专项费用` | 发票、支付截图 | 按通用发票和支付对应关系核对 |

不得用文件名、附件顺序、相似金额或日期猜测附件归属。参考报价基准由宿主提供，不是申请人必传附件；缺失、读取失败或无对应物料时，只说明制作单价未完成核对，不声称申请人未上传。豁免支付截图不豁免其他材料和已发现的冲突。

## 制作单价核对（归入第一项）

只对预算科目为 `终端建设费-终端形象制作费` 的明细逐项执行，混合科目单据按对应清单范围检查；不扩展到“推广费用-物料费”。先核实清单与明细的归属，再读取冻结的 `material.tpm_price_reference`。`status=ready` 时，`rows` 是财务参考表的物料、规格、单位和 H 列“含税指导价（元，1%）”；`source_row` 是原表行号。此表是共同审核基准，不是当前单据的支出证据。

- 逐项核对清单的材料编码、名称、材质规格及计价单位。编码和名称指向不同物料、规格不清或参考表无对应项时，说明具体冲突或缺口，不任选一个价格、按相近名称套价或猜测缺失规格。
- 按参考单位比较。清单按块或套、参考按平方米时，只有尺寸、数量和组合构成明确才能换算：单块面积为换算到米的长×宽，元/块除以单块面积得到元/㎡；多块合计金额须除以对应总面积。异形计价、损耗、双面计费或套装不明时不套用长宽公式。保留原单价、尺寸、换算过程和来源；比较前不四舍五入掩盖差异，展示时可以合理保留小数。
- 一律采用 H 列原值，不按发票税率调整，不因清单没注明税率而另加税额。比较范围不含安装和运输；已单列的安装运输行不参与制作比价，合并报价只有可信分项金额时才拆分，否则说明无法准确比价。安装运输不参与比价不等于从原核销金额中剔除。
- 高于、低于指导价均不设允许偏差，在第一项简短列出“物料、清单单价、指导价、差异方向”；同类差异可合并，但覆盖所有异常物料。价格差异或无法比价使第一项为 `uncertain`，`missing_evidence` 写需财务核实的差异原因或匹配缺口；只提示价格问题，不仅凭差异认定不合理。已确认缺件等原有 `fail` 仍保留，同时列出价格问题，不用价格提示覆盖其他异常。
- 在第一项引用实际使用的 `material:tpm_price_reference.rows.<从0开始的索引>`，并引用清单内容与预算科目字段；工作笔记覆盖每个适用物料的一致、差异或无法比价结果，其他项目不重复价格警告。参考表未配置或不可读时说明“参考报价未加载成功，制作清单单价未完成核对，请财务核实”。宿主只能核验第一项通过时是否引用冻结表中的有效行，引用本身不能替代逐项比价。
- 第三项继续核对可信支付、发票和适用盖章清单金额，不把“指导价×数量”加入孰低核销，也不因高于或低于指导价改写核销金额。四项结构保持不变。

## 签字意见

结构化决定和签字意见均完整保留上述四项，复用公共输出：通过显示 `✅`，明确不符显示 `❌`，证据不足显示 `⚠️`。通过项只写一句给审批人的结论，不复述取证过程、明细数量、图片覆盖、字段路径、文件位置、豁免推理或发票挂票位置。四项正常结论按以下语气写：

- 附件完整性：通过写 `附件完整。`；确认缺件时按行写 `第 N 行缺少 XXX，请补充。`（多行用顿号并列）；无法比价或价格异常按上文列明具体事项，请财务核实，不改写成缺少附件。通过时 `evidence_refs` 必须引用该行 `yskm` 预算科目字段（宿主复核，未引用即降级为需人工判断）。
- 发票关联与金额：通过写 `已关联发票，金额 X 元，与报销金额一致。`；OA「关联发票」全部未解析或为空且无其它可信关联记录时**不得判通过**，写 `关联发票未读取到关联记录，请财务核对原单。`，不得用附件名称、附件内发票号或金额相等替代关联关系，也不得把未解析字段列为通过证据。
- 金额孰低核销：默认 `按 X 元核销。`；支付截图、发票与盖章版制作清单（仅 `终端建设费-终端形象制作费`）金额不一致或涉及清单总额时，写 `支付截图 A 元、发票 B 元、清单总额 C 元，按 X 元核销。`
- 支付公司一致：`使用 XXX（发票购买方）账户支付。`

有问题时才简洁写明具体缺口、冲突或需补材料。同一缺口在最相关项说明，其他项只说明受到的实际影响，不复制成多条警告。不再输出仅含问题的清单。

历史 V1/V2 六项及 V3 四项审核包保持原始冻结内容，用于回查；新工作进程只处理 V4 四项包。V4 在第一项增加冻结参考报价核对，旧包不得直接换版本后继续审核，须按原恢复授权重新准备材料。
