# TPM 小额市场费规则包

本规则包仅适用于 `workflow_key=tpm_small_marketing_fee`，规则版本为 `tpm_small_marketing_fee:1`。先执行[共享结果接口](../result-contract.md)，不得读取或复用普通 `small_marketing_fee` 的科目、SAP 客户编码或费用承担主体规则。

AI 只形成预审意见，不批准、不退回；退回权归财务。附件缺失属于业务问题，不是技术阻断。对 `fail` 或 `uncertain` 必须写出具体缺失材料、冲突值、照片数量、定位缺口或无法建立的对应关系，不得只写“异常”“无法识别”“需补充”或“附件不完整”。

## 问题具体性

问题具体性按可定位的业务对象和事实判断，不要求使用固定动词。具体事实包括原值或金额、明细序号、对应关系两端，或者明确缺失的材料和字段。“无法逐字匹配”“不能按孰低原则确定”“字段未解析”“非纸质发票”等自然表达满足上述条件时属于具体结论；“事项未确认”“对应关系不可推定”等没有具体事实的套话仍拒绝。

## 固定审核项

1. 费用科目：逐字读取当前明细费用科目，只按下表精确匹配；无法可信读取或不在表内时使用 `⚠️`，说明待财务确认的原值，不按相似词猜测。
2. 科目附件完整性：按每条明细匹配下表必需附件。明确缺失时使用 `❌` 并逐项列出；附件存在但归属、内容或读取完整性不可信时使用 `⚠️`。
3. 关联发票与收据：只识别 OA 明细“关联发票”处的发票，仅判断是否为纸质发票，不扩展发票类型分类；核对购买方、销售方、金额和明细归属。收据必须核对购买方、事项、金额、收款人姓名、身份证号和手机号。
4. 支付凭证：对公支付无需支付截图，不设置员工代垫场景。允许多张支付凭证合计对应一张发票，但必须排除重复截图，同一截图或同一支付事实只计一次；对应关系或去重无法确认时使用 `⚠️`。
5. 金额孰低核销：按发票可归属金额与去重后的实际支付金额孰低形成意见，不设置容差；任一金额或对应关系不可信时使用 `⚠️`。
6. 主体一致性：发票购买方必须为思念公司，销售方为实际外部供应商；需要核对印章或收款人时按下表执行。公司、印章、销售方或收款人不一致时列明冲突原值，不做名称归一化。

## 10 类费用科目与附件要求

| 费用科目 | 必需附件 | 专项核对 |
| --- | --- | --- |
| `终端建设费-终端形象制作费` | 发票、广告公司盖章版制作清单、执行后现场定位照片 1 张 | 制作清单内容结合参考报价单和照片核对数量、样式；清单印章与发票销售方一致；缺支付截图时再核对收款人姓名 |
| `推广费用-物料费` | 发票、制作清单或购买明细、支付截图、制作完成定位照片 | 清单或明细与定位照片一致 |
| `终端建设费-其他` | 发票、支付截图 | 按通用发票和支付对应关系核对 |
| `通路促销-订货会会务费` | 关联申请签报、发票、费用清单、签到表、支付凭据；每个申请不少于 4 张订货会现场多角度全局定位照片 | 逐个申请核对照片数量、全局视角和定位信息，缺少会议材料时明确列出 |
| `推广费用-产品赠品费` | 发票、支付截图 | 按通用发票和支付对应关系核对 |
| `推广费用-试吃品费` | 发票、支付截图、执行试吃定位照片 | 说明照片缺失或定位无法确认的具体情况 |
| `促销员费用-管理费` | 发票、支付截图 | 按通用发票和支付对应关系核对 |
| `促销员费用-激励费` | POS 复核数据表、激励政策（申请签报或签报截图） | POS 表只检查是否上传，不识别表内内容 |
| `促销员费用-统筹福利` | 关联申请签报、发票、支付截图 | 核对签报与当前明细的归属关系 |
| `促销员费用-专项费用` | 发票、支付截图 | 按通用发票和支付对应关系核对 |

对公支付与表中“支付截图”要求冲突时，以可确认的对公支付事实为豁免依据；无法确认是否对公时使用 `⚠️`，说明缺少的付款主体或收款关系证据。不得把文件名、附件顺序、相似金额或相近日期当作归属证明。
