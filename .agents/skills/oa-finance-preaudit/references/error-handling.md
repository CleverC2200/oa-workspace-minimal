# 停止规则

下列情况属于技术失败，停止当前单据并报告具体缺口：

- requestId 或业务流程编号无法唯一定位，包括业务流程编号数据库精确查询返回零条或多条；
- 业务流程编号数据库查询不可用、超时或失败；
- OA 登录、权限或读取失败；
- 资源无法证明属于当前流程；
- OA 已声明或返回的相关附件资源缺失、损坏、未完整读取或 PDF 页面覆盖不全；
- 权威接口失败且该数据是当前审核项的必要依据；
- FlowEngine 未生成唯一的 `schema_version=1`、`kind=preaudit_material` 冻结材料；
- 只读测试过程中出现任何写入、流转或 automation 变更请求。

业务上的 `❌/⚠️` 不是技术失败。附件内容确实可读，但某项事实没有出现或关系不足时，在对应审核项标为 `⚠️`；不得伪造证据，也不得换旧 runner 手工提交。

业务支持费完整材料明确显示流程完全没有附件时，按已确认口径在“附件完整性”项使用 `❌`，不作为采集技术失败；若 OA 已声明或返回附件但实际无法取得或读取，仍按技术失败停止。

汇报时只给脱敏的失败阶段和原因，不输出附件正文、凭据、Cookie、token 或原始接口响应。
