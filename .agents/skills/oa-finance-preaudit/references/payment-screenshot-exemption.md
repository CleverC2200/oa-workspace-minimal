# 六类财务：对公付款免支付截图

适用于差旅费、业务招待费、业务支持费、小额市场费、TPM 小额市场费和通用费用。先按当前流程确定必需材料；仅对要求支付截图的费用应用本规则。固定审核项及其它流程的范围不变。

## 入口：先核对已有支付截图

先按当前流程核对已提供截图的实际支付金额、最终交易状态及与当前费用的可信对应关系。已有有效支付截图的明细按正常支付证据核验，不进入下方截图豁免及其人员补充材料分支。普通员工垫付报销，不能仅因 OA 报销收款人与发票销售方不同名，或截图未显示付款人姓名，要求员工主数据、委托代付款截图或委托收款函。

仅对科目要求支付截图、但没有有效支付截图的明细，进入下方豁免核验。截图存在但金额、状态或费用归属未核实时，保留具体事实或关系缺口；未核实不等于确认未支付。已有材料确认未支付、支付失败、退款或金额冲突时，仍按当前流程报告，不因豁免消除异常。

实际交易收款对象与发票或费用之间确有冲突，或对应关系未核实时，仍须核对并说明具体问题。OA 中接受报销款的员工不是因此自动成为实际交易收款对象；不得把员工与销售方不同名当作上述冲突。

## 缺少有效支付截图时的豁免核验

从表单“收款人员名称”或“收款人名称”读取收款人，从当前单据关联发票正文或权威发票资料读取销售方。收款人员 ID 未解析时，使用同一收款记录已读取的名称。本单仅有一个收款人时，直接与本单关联发票销售方逐字比较；多笔收款或多张发票按可信对应关系分别核验，同一张发票稳定共享时只核对一次。保存双方名称原值和关联依据，不做简称、括号、空格或公司类型归一化。

| 核验结果 | 处理 |
| --- | --- |
| 收款人与关联发票销售方逐字完全一致，关系可信 | 按对公付款免支付截图；无需再取实际付款凭据证明截图豁免 |
| 名称缺失、销售方未读取或对应关系不明 | 使用 `uncertain`，记录具体名称或关系缺口；缺截图本身不足以判 `fail` |
| 已确认不同名 | 按当前流程的人员关系、支付证据及补充材料要求继续核验，不豁免 |

购买方、合同乙方、文件名、相似金额、附件顺序及选择企业支付接口都不能替代销售方或关联关系。一组同名不能豁免没有可信对应关系的其他费用。

## 材料与金额边界

豁免仅免支付截图，发票、合同、制作清单、照片等其他必需材料仍须核对。其他必需材料确认缺失时，对应项仍为 `fail`；材料已关联但系统尚未读取时，只说明未完成内容核对，请财务查看原单，不能声称申请人未上传。

已豁免时，不在其他审核项重复要求同一支付截图或实际付款凭据。申请/申报金额仍是申请/申报金额，豁免不证明已经实际支付；已确认豁免且没有可验证实际支付金额时，仅比较该流程其他已确认且同范围的金额，不因该缺失再次要求截图，也不把申请金额改写成实际支付；有可验证实际支付、退款或冲突时仍按原孰低规则。保留原去重及费用范围规则；支付失败、退款或金额冲突仍按真实事实报告，不能因截图豁免忽略。

`warnings` 中的 `invoice_document_reference_unresolved` 表示 OA 已关联发票文档，但当前接口没有可下载文件，正文尚未读取。它不表示未上传，也不否定已取得的可信发票云购买方或销售方；按实际缺少的事实判断受影响项目，不把已核实事实一并作废。仅有文档 ID 和显示文件名时，不构造下载链接或猜测文档内容。

## 意见

在当前流程的附件/支付证据项简述结果，引用收款人名称、销售方和关联关系证据；其余必需材料也符合时才能判整项通过。小额市场费仍按现有输出合同同时写“支付截图”和“发票”，例如“发票已核验，对公付款免支付截图。”。其余流程沿用固定项、金额及公司结论格式。
