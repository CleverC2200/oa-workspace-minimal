# ADR 0003：本地运行视图与受控留存

- 状态：已接受
- 日期：2026-08-22
- 关联：GitHub Issue #52

## 背景

FlowEngine 已把事实保存为每个 attempt 的原子 JSON。状态查看和 30 天清理若再建设数据库、HTTP、MCP 或常驻进程，会形成第二套状态源；若让 Codex 自行遍历和删除目录，又会扩大上下文和误删风险。

## 决定

继续使用同一个本地 JSON CLI，增加运维动作 `status` 与 `prune`。`status` 只读取 attempt 状态，输出流程、脱敏哈希、计数、年龄、三维状态和失败码。`prune` 依次执行列举、生成带指纹计划、全量校验受限根和全部相对路径、最后归档或删除。

每类流程创建时间最新的 attempt、所有未闭合 attempt、无效状态和 `write_state=unknown` 始终保留。30 天内的旧已闭合 attempt 移入同一标记根的 `.archive/`；严格超过 30 天后删除。已归档 attempt 继续参与超期扫描。重复应用同一计划时，不存在的目标记为 `missing`。

运行根必须由人工显式写入 `.oa-retention-root` 标记。留存期固定为 30 天，计划只在生成后 5 分钟内有效。根或目标包含符号链接、绝对路径、越界路径、重复目标、未知动作、不完整计划或执行时新增目标时，在第一项文件变更前整体失败。

## 范围

本票只交付本地状态和文件生命周期。现有任务回调接口继续用于测试和以后接入任务归档，但不携带真实任务系统凭据，不自动归档 Codex 任务，不创建定时任务，也不执行 OA 写入。

## 结果

- 人、Codex 和后续自动化读取同一状态事实与同一版本化输出。
- 运维状态不进入业务审核上下文。
- 清理计划可测试、可重放且不暴露业务身份或绝对路径。
- 项目仍不需要数据库、HTTP、MCP 或常驻 daemon。
