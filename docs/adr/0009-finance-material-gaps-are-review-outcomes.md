# ADR 0009：财务材料缺口属于预审结果

- 状态：采集失败降级提交的决定已被 [ADR 0011](0011-collection-failure-blocks-opinions.md) 取代；正常材料上的业务缺口仍是预审结果
- 日期：2026-08-23
- 关联：GitHub Issue #73

## 背景

四类财务流程曾把材料采集失败、附件归属不可信或读取不完整统一转换为 `needs_admin`。这会让 AI 预审成为流程闸门，也使财务看不到本应由其结合 OA 原始单据判断的材料缺口。

## 决定

- 只有审批单据身份、唯一冻结 attempt、动作/状态完整性、写入授权或最终提交目标不可信时硬停止。
- 四类财务流程的材料采集不可信时，脚本丢弃全部候选材料，冻结只含脱敏 `collection_gaps` 的降级材料，并生成 `review_required`。
- 审核包列出 `required_uncertain_items`；Agent 必须针对当前流程逐项生成动态 `uncertain` 结论，说明缺口并交财务判断。脚本拒绝把这些项目判为通过或不符合。
- 签字意见的首行、固定项目名、顺序和状态符号由脚本确定；项目状态、结论、证据和缺口由 Agent 基于当前审核包生成，再由脚本校验并拼接。
- 包装校对依赖可直接观察的可信图片，不采用财务降级路径。

## 结果

- 财务材料问题不再阻断 AI 预审意见，财务能够看到明确的待判断事项。
- 不可信材料不会进入模型判断，也不会被误写成“未发现问题”。
- 执行安全边界仍由 FlowEngine 确定性校验，Agent 不能绕过动作令牌、冻结指纹或写入授权。
