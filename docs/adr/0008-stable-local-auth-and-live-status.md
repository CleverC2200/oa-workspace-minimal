# ADR 0008：稳定本地凭据与实时状态自检

- 状态：已接受
- 日期：2026-08-23
- 关联：GitHub Issue #66

## 背景

OA 运行凭据原先只保存在工作树内的忽略文件中。普通 Git 操作不会修改它，但删除工作树、重新克隆或清理忽略文件会同时删除运行配置。既有 `status` 只汇总本地运行事实，无法一次确认认证和实时待办映射是否健康。

## 决定

- 默认从工作树外的 `~/.config/oa-workspace-minimal/oa-auth.env` 读取 OA 配置；进程环境变量可覆盖，`OA_AUTH_ENV_FILE` 可选择其他工作树外文件。
- 仓库内 `.env` 和 `.env.oa-auth` 只保留兼容回退。所有被读取的配置文件必须是权限不超过 `600` 的普通文件。
- 不新增第五个公开命令。实时自检放在既有 `status --check-live`，继续返回一个版本化 JSON。
- 实时自检只调用认证和待办只读接口，输出配置来源、健康状态及按流程聚合的数量；不输出值、身份、单号或材料，不领取、冻结或提交单据。

## 结果

- 删除或重建工作树不再删除主要 OA 运行配置；工作树回退仍方便已有本地环境平滑迁移。
- 人和 Codex 仍只需理解 ADR 0005 冻结的四个公开命令。
- 配置缺失、权限不安全或实时认证失败时安全退出，不会被解释为空队列或写入授权。
