# ADR 0011：材料读取失败不生成可提交意见

- 状态：已接受
- 日期：2026-10-14
- 关联：GitHub Issue #275
- 取代：ADR 0009 中采集失败后冻结空材料并提交逐项 uncertain 意见的路径

## 背景

自动读取失败时，旧路径丢弃全部候选材料，仍将所有审核项未完成核对的意见提交 OA。2026-10-14 用户明确要求这种情况卡在提交前。技术读取失败不能代替基于原材料形成的业务判断。

## 决定

当前采集及提交门统一由 FlowEngine 维护，具体条件见[当前合同](../../.agents/skills/oa-finance-preaudit/references/flow-engine-contract.md)。新采集失败不生成审核包，旧空材料或降级待审动作也不能到达 Writer。原错误细码及冻结材料保留，历史已提交意见继续只读验真，不重放。

## 结果

系统可能需要修复读取问题后另行授权恢复，不能用零信息意见结束当前单据。真实材料缺项、冲突和口径不明继续由 Agent 形成业务意见；它们仍不代表批准或退回。源码修复及离线测试不证明生产已生效。
