# ADR 0012：处理尝试以 state 为唯一可变事实源

2026-10-18，Issue #583。此决定替代 ADR 0001、0002 中动作与当前动作投影的持久化部分。

原先一次状态转换需要改写 `action.json`、`state.json` 和流程投影，崩溃恢复必须解释它们之间的落盘窗口。新 attempt 只更新 `state.json`；`action.json` 创建后保持原字节，仅绑定单据身份和本地路径，其摘要保存在 state。公开动作由校验后的 state 派生，授权、冻结输入、决定绑定和完成锁仍由原边界验证。引用摘要不证明当前写入资格，也不能替代实际发送上下文中的 state 指纹。

财务与通用附件识别共享 `apps.attempt_action` 的只读协议解析和安全文件读取，避免通用连接层依赖财务编排或复制校验。创建与状态写入留在财务模块，`review_context` 仍保存本次实际发送事实；共享读取不授予写入资格。

旧动作按原合同读取，显式推进旧 attempt 时绑定其原始动作字节，仅更新 state；读取历史不迁移、不重写。历史中断按保存的 interrupted-state 解释 interrupted-action。新引用不能通过删去 state 的规则版本进入旧版冻结合同。闭合 state 保留当前规则版本，公开动作不暴露内部决定绑定。

`current-action.json` 没有现役消费者，停止新写并保留已有文件。这样减少了一份可漂移的状态副本；代价是新消费者必须通过现有读取入口取得当前动作，不能把引用文件当成动作快照。
